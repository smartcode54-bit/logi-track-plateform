# 📖 Index of Cloud Functions & APIs

This document outlines the available Firebase Cloud Functions (API endpoints), their triggers, and brief descriptions for **LogiTrack**.

## 📁 Functions File Structure (`logitrack-web/functions/src/`)

All new API and backend logic is implemented as **Firebase Cloud Functions** (mostly 2nd Gen `onCall` callable) which enforces App Check directly on call.

| File Name | Function Name | Type & Trigger | Description |
| :--- | :--- | :--- | :--- |
| **`auth.ts`** | `setAdminClaims` | `onCall` (Callable) | ตั้งสิทธิ์ Custom Claim `admin: true` ให้กับผู้ใช้งานที่ระบุ UID |
| | `setDriverClaims` | `onCall` (Callable) | ตั้งสิทธิ์ Custom Claim `driver: true` สำหรับคนขับควบคุมรถ |
| | `checkAdminStatus` | `onCall` (Callable) | ตรวจสอบสถานะว่า UID ผู้เรียกสิทธิ์เป็น Admin ใน Auth หรือไม่ |
| **`users.ts`** | `getUsers` | `onCall` (Callable) | ดึงรายชื่อพนักงาน Admin / ผู้ดูแลระบบทั้งหมดมาแสดงหน้าจัดการสิทธิ์ |
| | `updateUserRole` | `onCall` (Callable) | แก้ไขสิทธิ์ (Role/Permissions) ของแอดมินหรือผู้ใช้งาน |
| | `createUser` | `onCall` (Callable) | สร้างผู้ใช้งานพร้อมสิทธิ์ลงใน Firebase Auth ระบบหลังบ้าน |
| | `syncExistingUsers` | `onCall` (Callable) | ฟังก์ชันแบ็กอัป/ซิงค์รายชื่อพนักงานที่ตกค้างให้ตรงกับตารางเช็คลิสต์ |
| **`triggers.ts`** | `onUserCreated` | `auth.user().onCreate` | **1st Gen**: ทริกเกอร์สร้าง Profile ใน Firestore เมื่อผู้ใช้ลงทะเบียนสำเร็จ |
| | `onUserDeleted` | `auth.user().onDelete` | **1st Gen**: ทริกเกอร์ตามลบข้อมูลพ่วง Profile ออกจากระบบเมื่อผู้ใช้ลบ ID |
| | `createDriverAccount`| `onCall` (Callable) | สร้าง Account สำหรับคนขับ (Driver) ลงสู่ระบบแบบกำหนด metadata |
| | `updateDriverAccount`| `onCall` (Callable) | แก้ไขโปรไฟล์ หรือสถานะของ Account คนขับขี่ |
| | `notifyTaskUpdate` | `onCall` (Callable) | ยิง Notification แจ้งเตือนเมื่อมีการจ่าย/อัปเดตงานใหม่ให้ Driver |
| | `getNextTaskId` | `onCall` (Callable) | ดึงลำดับ ID สำหรับสร้างรหัส Task งาน Line-haul ถัดไปอัตโนมัติ |
| **`distances.ts`** | `computeHubSocDistances`| `onCall` (Callable) | ดึง API Google Maps Distance Matrix คำนวณระยะทางรวม Source/SOC |
| **`chat.ts`** | `notifyChatMessageCreated`| `onCall` (Callable) | ยิง Push Notification อัพเดทคนขับเมื่อมีห้องแชทพัสดุถูกส่งข้อความมา |
| | `sendBroadcast` | `onCall` (Callable) | ยิงแจ้งเตือน (Broadcast) ทั้งระบบหรือเป็นกลุ่มเฉพาะแอดมิน |
| | `markBroadcastRead` | `onCall` (Callable) | บันทึกสเตตัสการเปิดอ่าน (Opened) ของ Notifications บรอดแคสต์ |
| **`cartrack.ts`** | `syncVehicleLocations`| `onSchedule` (CRON) | รันอัตโนมัติตามตารางเวลาเพื่อดูดพิกัดล่าสุด ยอด Odometer และ Fuel จาก API Cartrack เก็บลง Firestore |
| **`holidays.ts`** | `saveGeneratedHolidays`| `onCall` (Callable) | บันทึกรายการวันหยุดประจำปีที่แอดมินจัดทำอัตโนมัติเข้าสู่ Database |
| | `deleteHoliday` | `onCall` (Callable) | ลบบันทึกวันหยุดออกจากปฏิทินขององค์กร |
| | `saveHoliday` | `onCall` (Callable) | บันทึกเพิ่มเติมวันหยุดเดี่ยวรายข้อมูลเดี่ยว |

## 💡 วิธีการเรียกใช้งานจาก Client (Web / Next.js)

```typescript
import { getFunctions, httpsCallable } from "firebase/functions";

const functions = getFunctions();
const computeHubSocDistances = httpsCallable(functions, "computeHubSocDistances");

// สั่งรันฟังก์ชันและส่ง payload
const response = await computeHubSocDistances({ originIds: [...] });
console.log(response.data);
```

> [!TIP]
> ทุกฟังก์ชันในลิสต์ด้านบนบังคับใช้ `enforceAppCheck: true` เพื่อความปลอดภัย (ห้ามเรียกจาก Postman โดยตรงโดยไม่มี App Check token)
